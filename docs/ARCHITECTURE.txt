
CIVICTRACK ARCHITECTURE
======================

VERSION
-------

v1 - First frontend prototype


1. APPLICATION STRUCTURE
------------------------

app/main.py
    Starts the local Python HTTP server.

app/templates/index.html
    Contains the website's HTML structure.

app/static/css/style.css
    Controls website appearance and responsive layout.

app/static/js/app.js
    Controls frontend interactions and complaint data.

3. COMPLAINT SUBMISSION
----------------------

1. Citizen fills in the HTML form.
2. JavaScript reads the submitted values.
3. JavaScript creates a complaint object.
4. Complaint is added to application state.
5. Browser localStorage saves the data.
6. Dashboard updates its statistics.
7. Complaint table displays the new record.


4. CURRENT DATA STORAGE
-----------------------

Data is stored using browser localStorage.

The current prototype does not use SQLite.

Data is local to the browser and its origin.
