
CIVICTRACK
==========

Public Grievance and Civic Issue Reporting System

PROJECT OVERVIEW
----------------

CivicTrack is a web-based civic issue reporting prototype.

It aims to help citizens report local infrastructure and
public-service problems and follow their progress.

EXAMPLE ISSUES
--------------

1. Damaged roads
2. Potholes
3. Broken streetlights
4. Water leakage
5. Blocked drainage
6. Garbage collection problems

TECHNOLOGY STACK
----------------

Frontend:
- HTML
- CSS
- JavaScript

Local development server:
- Python
- Python standard library

- Git

CURRENT FEATURES
----------------

- CivicTrack homepage
- Complaint submission form
- Complaint dashboard
- Complaint status display
- Complaint filtering
- Responsive website layout
- Browser localStorage persistence

HOW TO RUN
----------

From the project root:

    python app/main.py

Open this address in your browser:

    http://127.0.0.1:8000/

Stop the server with:

    Ctrl + C

IMPORTANT LIMITATIONS
---------------------

This version is a frontend prototype.

Complaints are stored in the browser's localStorage.

There is currently:
- No backend API
- No user authentication
- No shared database
- No administrator system
- No government integration
